# 全景漫游独立产品 PRD v1.0

> 定位：可复用的轻量 360° 全景漫游（播放 + 最简制作），月子中心及其他项目均可嵌入
> 对标：Matterport 的「能逛房间」最低档；不做自动建模、量尺寸、复杂剪辑
> 状态：范围与技术栈已确认；待确认项已于 2026-10-14 拍板

## 1. 目标与成功标准
- 门店/商家能自己上传几张全景图，标热点，生成一个可分享的漫游链接
- 顾客在微信小程序或手机浏览器里流畅拖动、缩放、点热点换房间
- 其他业务（月子、门店展示等）只需嵌链接或 web-view，不重复造播放器

成功标准：一条漫游从上传 → 标热点 → 手机打开流畅到可验收；嵌入到至少一个业务项目（如月子中心）能打开。

## 2. 范围

### P0（首版必做）
**播放（顾客）**
1. 全景拖动查看、双指缩放
2. 热点：点击跳到下一场景（房间）
3. 场景缩略图列表：底部或侧边展示各场景缩略图，点击切换（与热点跳转并存）
4. 加载进度与失败提示
5. 分享链接：打开即进播放页（H5）；小程序内用 web-view 打开同一 H5

**制作（商家 / 运营）**
6. 登录后台（平台账号；已确认：首版单租户，一个后台管所有作品，不做多商家自助注册）
7. 作品管理：新建 / 编辑 / 删除 / 上下架
8. 场景管理：上传全景图（jpg/png）、排序、设封面场景、场景名称
9. 热点标注：在全景预览上点选位置，填写标题、目标场景
10. 生成分享链接与嵌入说明（复制链接）

**系统**
11. 图片上传至对象存储（OSS）+ CDN
12. 大图压缩 / 合适分辨率策略（上传时限制大小与最长边）【假设：单张 ≤ 20MB，最长边建议 ≤ 8192】

### P1（第二版）
- 多租户：每个客户自己的账号与作品隔离
- 热点加说明文案 / 外链（打电话、打开预约页）
- 作品访问统计（打开次数）
- 陀螺仪跟随（手机晃动看房间）

### P2（以后）
- 自动拼接 / 多图拼一张
- 楼层平面图导航
- 付费套餐与用量计费
- 原生小程序内渲染（去掉 web-view）

### 明确不做（v1.0）
- Matterport 式三维网格建模、量尺寸、家具摆放
- 专业剪辑时间轴、音乐、解说音轨
- 实景拍摄硬件方案与指导 App

## 3. 角色
| 角色 | 端 | 权限 |
|---|---|---|
| 平台运营 | Web 后台 | 管理全部作品、场景、热点 |
| 访客 | H5 / 小程序 web-view | 仅播放已上架作品 |
| 业务系统 | 嵌入方 | 配置作品链接或 ID，跳转 / web-view |

已确认：首版不做门店自助注册；由平台运营代建作品，或给客户开一个运营账号。

## 4. 核心流程

## 5. 技术栈（已确认）
| 层 | 选型 | 原因 |
|---|---|---|
| 播放器 | Photo Sphere Viewer（Three.js） | 成熟、轻量、热点/多场景现成、文档全 |
| 播放壳 | 独立 H5 页 | 小程序用 web-view 复用同一套，避免原生 3D 坑 |
| 小程序入口 | uniapp（可选薄壳） | 仅负责打开 web-view / 分享 |
| 制作后台 | Laravel + 管理后台（Filament 或等价） | 与现有项目一致，好招人 |
| 存储 | 腾讯云 COS + CDN | 已确认用腾讯云；大图走 CDN |
| 部署 | 独立域名与服务 | 与月子等业务解耦，多项目共用 |

## 6. 数据模型（逻辑）
- **作品 tour**：名称、封面、状态（草稿/已上架）、分享码、创建时间
- **场景 scene**：所属作品、名称、全景图 URL、排序、是否初始场景
- **热点 hotspot**：所属场景、目标场景、球面坐标（yaw/pitch 或等价）、标题
- **运营账号 user**：登录用 【假设：首版简单账号表即可】

## 7. 接口与嵌入约定（概要）
- `GET /t/{share_code}` → 播放页（公开）
- 后台 REST：作品 / 场景 / 热点 CRUD（需登录）
- 业务嵌入：配置 `播放页完整 URL`，月子中心等项目后台填自己的作品链接即可（取代原 720 云 AppID 方案时可平滑切换）

## 8. 体验与性能要求
- 中端安卓机打开首场景：目标 3 秒内出图（视网速；CDN 前提下）
- 拖动无明显卡顿；切场景有简短过渡，失败可重试
- 横竖屏均可；优先竖屏手机
- 未上架作品：链接打开提示「作品未发布」

## 9. 与其他项目的关系
- **独立产品**：单独仓库 / 单独部署，不绑死月子中心
- **月子中心**：后台「全景」配置项改为填本产品分享链接；小程序跳转或 web-view 打开
- **后续项目**：同样只嵌链接

## 10. 验收标准（节选）
- 上传 3 张全景图，标 2 个热点，手机浏览器打开可拖动、缩放、点热点换房
- 微信小程序 web-view 打开同一链接表现一致
- 删除某场景后，指向它的热点有提示或自动失效，不白屏
- 作品下架后，旧链接不可播放
- 单张超限图片上传被拒绝并提示
- 另一业务项目只需改配置链接即可打开，无需改播放器代码

## 11. 待确认 / 假设
1. 【假设】首版单租户运营后台，不做多商家自助注册
2. 【假设】单张全景 ≤ 20MB，建议最长边 ≤ 8192
3. 【已确认】腾讯云 COS + CDN
4. 【已确认】独立域名 + HTTPS
5. 【已确认】热点跳转 + 场景缩略图列表都做

## 12. 粗估工期（供排期，非正式报价）
熟悉栈的一人：播放 H5 约 2–4 天；上传 + 场景 + 热点后台约 3–5 天；OSS/CDN 与联调约 2 天；真机与嵌入约 2 天。合计约 **1.5–2.5 人周**（P0）。
